# FC VISION — proyecto inicial de negocio

## Incluye
- Página responsive en español.
- Herramientas demo interactivas.
- Sección de servicios con precios de prueba editables.
- Botones de contacto por correo (debes configurar tu correo).
- HTML, CSS y JavaScript, sin base de datos.

## Antes de publicar
1. En `index.html` y `script.js`, reemplaza `TU_CORREO@EJEMPLO.COM` por el correo de contacto que usarás.
2. Revisa los servicios y precios y no prometas resultados que no puedas entregar.
3. El chat es una demo de respuestas predefinidas; no es una IA real.
4. No añadas claves API secretas al HTML o JavaScript público.

## Publicación gratis con GitHub Pages
1. Descarga y descomprime el ZIP.
2. Crea una cuenta en GitHub y un repositorio público llamado `fc-vision`.
3. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz.
4. En Settings → Pages, elige Deploy from a branch, branch `main`, folder `/ (root)` y guarda.
5. Espera a que aparezca el enlace público en esa misma sección.

## Plan de ingresos
Empieza vendiendo servicios pequeños que puedas entregar: ideas para vídeos, calendarios de publicaciones o conceptos de identidad para equipos. Consigue autorización antes de usar logos de clubes o marcas. Registra pedidos y gastos, y revisa las reglas de cualquier plataforma de pago o programa de afiliados; por ser menor de 18 años, puede requerirse participación de un padre/madre/tutor.
